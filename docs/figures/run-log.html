Run 2 · drive-strength sweep

DNp09 never fires — at any drive, across a fortyfold range

Poisson drive onto the looming-sensitive LC4 population, six seeds per point. Three descending neurons recruit in a fixed order; a fourth stays at exactly zero everywhere. On a degree-preserving rewire all four stay at zero.

Open circles mark drive rates whose seed-to-seed spread exceeded 2× — excluded from the recruitment thresholds. At 5 Hz the spread is 8.2×.

Run 3 · structure predicts function

Share of excitation, not synapse count

LC4 makes 3,782 synapses onto DNp01 and only 2,279 onto DNp02 — yet DNp02 recruits first. What orders them is the fraction of each target's total excitation that LC4 supplies.

DNp09 receives exactly zero synapses from LC4. The graph answered in one query what the sweep spent six seeds on.

Run 4 · the visual pathway

Every stage is below threshold

Median synapses per connected pair along the columnar route to LC4. One spike needs about 162 synapses to fire a resting neuron in this model, so the chain attenuates at every step and a looming stimulus never arrives.

T4a → LC4 is not a weak connection. There is no connection.

Run 7 · object fixation

The real wiring aims; the control turns away

A dark target, the fly started off-axis, thirty control steps. On the measured graph the final bearing converges toward the target from every start. The rewired control diverges at large bearings — it does not merely aim worse.

Run 7 · Kenyon cell calibration

The sparse odour code has to be imposed

About 5% of Kenyon cells respond to a given odour in the animal, and that sparseness is what makes odours separable. At the model's default gain one glomerulus lights 88% of them.

The usable window is narrow: a factor of three either way gives a dense code or a dead one.

Run 8 · why learning stops

The MBONs that learn are not the ones that steer

Per mushroom body output neuron: the Kenyon cell input it receives, where dopamine-gated plasticity acts, against its output onto descending neurons, the only cells that move the animal.

Correlation —. MBON14 has the most Kenyon cell input and exactly zero descending output.

Run 9 · the ensemble readout

A balance sees what an average cannot

Reward-specific change in the mushroom body's output after odour conditioning, as percentage points of relative change. Averaging 97 cells of opposite sign hides it; weighting each by its influence on the motor output does not.

Odour B shows 4.4× more reward-specific signal in the balance. It remains small: 1.7 points of an 8.3% total change.
